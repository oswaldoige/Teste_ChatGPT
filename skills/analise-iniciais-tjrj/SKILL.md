# Analise Iniciais TJRJ

## When to use
- Use for cases awaiting the first judicial act after distribution.
- Use when the key task is to choose the correct initial order, remessa, emenda, or gratuity ruling.

## Workflow
1. Apply the shared rules from `$revisor-base-tjrj`.
2. Read [roteiro.md](references/roteiro.md).
3. Open [subtipos.md](references/subtipos.md) and jump to the exact subtype before drafting.
4. If the initial petition also contains an unresolved urgent-relief request, pair this skill with `$tutela-urgencia-tjrj`.

## Expected outcome
- Choose the correct initial act instead of recycling a generic citation order.
- Treat justice gratuity as its own decision point, not as a default courtesy clause.
