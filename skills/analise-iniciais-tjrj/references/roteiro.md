# Roteiro

## First-pass checks
1. Confirm the class, subject, parties, localizer, and latest events.
2. Check whether there is already a certidao about costs or justice gratuity.
3. Identify the true subtype before drafting anything.
4. In 3o Nucleo 4.0 cases, distinguish between a truly untouched initial filing and the first manifestation after redistribution from the origin court.
5. If the case arrived at the Nucleo after rulings, petitions, citations, or responses in the origin court, map those acts before choosing the subtype.
6. Search the model folder before writing.
7. Decide whether the case calls for:
   - common initial order
   - Fazenda Publica initial order
   - execution opening order
   - usucapiao order
   - remessa or declinio
   - order to prove gratuity
   - denial of gratuity
   - specialized 3o Nucleo 4.0 initial act

## Mandatory cautions
- If the class is `Procedimento do Juizado Especial Civel` but the case landed in a Vara Civel, analyze remessa or declinio before any generic citation order.
- Never use the same initial order text for private defendants and Fazenda Publica.
- Review justice gratuity separately even when there is a declaration of poverty.
- If the chosen subtype has a gabinete base model that fits the case, draft from that text with minimal deviation. Do not replace the model's phrasing with a merely equivalent paraphrase.
- In passive litisconsortium, individualize the procedural status of each defendant before drafting. The spontaneous appearance, citation, or contestation of one defendant does not regularize the passive pole as a whole.
- In the first manifestation of the 3o Nucleo 4.0 after redistribution, do not skip the standard gabinete opening block when the dossier supports it.
- Never state that the plaintiff or defendant said, requested, admitted, opposed, accepted, waived, recognized, demonstrated, or expressly manifested anything unless that exact content is identifiable in the dossier. If the file is silent, draft the act without imputing any statement or position to the party.
