# Cumprimento Sentenca TJRJ

## When to use
- Use for cumprimento de sentenca, impugnacao, post-judgment enforcement, obligation-to-do compliance, and satisfaction measures.

## Workflow
1. Apply the shared rules from `$revisor-base-tjrj`.
2. Read [fluxo.md](references/fluxo.md).
3. Open [impugnacao-e-astreintes.md](references/impugnacao-e-astreintes.md) when the case turns on defenses, compliance proof, or coercive measures.
4. Generate two `.docx` versions only if the ruling is truly complex; otherwise one file is enough.
