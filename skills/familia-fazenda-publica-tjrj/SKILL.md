# Familia Fazenda Publica TJRJ

## When to use
- Use when the dispute is governed primarily by public-law relations involving public entities, administrative acts, public servants, state payments, or public-law obligations.
- Use when Fazenda Publica constraints materially affect the relief, proof, or dispositive structure.

## Workflow
1. Read [guia.md](references/guia.md).
2. Confirm that the case demands a public-law matrix rather than a generic civil one.
3. Preserve the canonical Fazenda Publica model architecture.
4. Check compatibility of relief, burden allocation, consectarios, and sucumbencia with the public-law regime of the case.

## Output expectation
- The draft must read as a public-law act, with the administrative or statutory regime clearly visible.
- Avoid importing private-law assumptions mechanically where the Fazenda Publica regime changes the result.
