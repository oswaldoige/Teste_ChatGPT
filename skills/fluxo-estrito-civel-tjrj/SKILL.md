# Fluxo Estrito Civel TJRJ

## When to use
- Use in every run where the user wants maximum fidelity to gabinete models and phase control.
- Use especially in repetitive families and in 3o Nucleo 4.0 workflows.

## Workflow
1. Read [checklist.md](references/checklist.md).
2. Before drafting, close the six mandatory internal answers from the checklist.
3. If any answer is uncertain, do not draft yet. Reopen the dossier and the model search first.
4. Do not reopen procedural steps that were already exhausted in substance, even if the prior petition was not formally labeled with the expected name.
5. Draft with minimal deviation from the selected gabinete model.
6. Run the postflight gate before saving the `.docx`.

## Output expectation
- No drafting without exact phase closure.
- No drafting without exact model-path closure.
- No delivery without postflight confirmation.
