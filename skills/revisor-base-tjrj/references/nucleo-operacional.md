# Operational Nucleus

## Purpose
- Keep the model search centered on a small and curated canonical nucleus.
- Separate operational search from the historical archive.
- Preserve recognizable gabinete standards instead of over-compressing the available matrices.

## Primary root
- `modelos`

## Search order
1. `00_NUCLEO_OPERACIONAL`
2. `00_PRIORITARIOS_AUTOMACAO`
3. Specialized folder for the matter or chamber
4. Correlated archive folders
5. Reference PDFs only when necessary

## Routing logic
- First identify the provimento: `tutela`, `saneador`, or `sentenca`.
- Then identify the macrofamilia: `consumidor`, `civel contratual`, or `Fazenda Publica`.
- Search the corresponding folder in the operational nucleus before opening the wider archive.

## Curatorship rule
- Keep only the canonical models that should actually drive the automation, but do not force the nucleus to be artificially tiny.
- In recurring families, prefer 3 to 6 canonical models when that is what preserves the gabinete's standard openings, reasoning flow, and dispositive cadence.
- Move small variations into reusable blocks instead of multiplying standalone models.
- After choosing the main model, consult the corresponding `90_BLOCOS_REUTILIZAVEIS` folder whenever the opening of the reasoning, burden-of-proof discussion, or dispositive bridge has a stable wording pattern.
- Use the wider archive as consultation backup, not as the default starting point.
