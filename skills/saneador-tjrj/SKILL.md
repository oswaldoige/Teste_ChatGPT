# Saneador TJRJ

## When to use
- Use after contraditorio is formed and the case needs a saneadora, proof definition, or issue delimitation.

## Workflow
1. Apply the shared rules from `$revisor-base-tjrj`.
2. Apply `$roteamento-modelos-tjrj` to identify the canonical saneador folder before opening the wider archive.
3. Choose and apply the material-family skill that best fits the case:
   - `$familia-consumidor-tjrj`
   - `$familia-civel-contratual-tjrj`
   - `$familia-fazenda-publica-tjrj`
4. Read [fluxo.md](references/fluxo.md).
5. Open [variantes.md](references/variantes.md) and choose the correct branch inside that prior macrofamilia classification: Vara Civel comum or 3o Nucleo 4.0.
6. Draft only the saneadora that matches the current phase. If the case is already mature for judgment, do not force a pseudo-saneador.
