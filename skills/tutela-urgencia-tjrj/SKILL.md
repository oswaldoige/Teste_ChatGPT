# Tutela Urgencia TJRJ

## When to use
- Use for any pending `tutela de urgencia`, liminar, reconsideration, complement, or descumprimento linked to a provisional measure.

## Workflow
1. Apply the shared rules from `$revisor-base-tjrj`.
2. Apply `$roteamento-modelos-tjrj` to identify the canonical tutela folder before opening the wider archive.
3. Choose and apply the material-family skill that best fits the case:
   - `$familia-consumidor-tjrj`
   - `$familia-civel-contratual-tjrj`
   - `$familia-fazenda-publica-tjrj`
4. Read [fluxo.md](references/fluxo.md).
5. Open [familias.md](references/familias.md) only to refine the subject matter inside the chosen macrofamilia before drafting.
6. If the decision is complex, produce complete and concise `.docx` versions.

## Output expectation
- Decide among defer, defer parcialmente, indefer, reconsiderar, complementar, or enforce.
- Prefer the canonical tutela matrix from `00_NUCLEO_OPERACIONAL` whenever it is aderent.
- Calibrate the measure to the proven risk instead of mechanically granting everything requested.
