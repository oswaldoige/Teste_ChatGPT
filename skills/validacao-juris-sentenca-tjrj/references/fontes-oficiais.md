# Fontes Oficiais

## Priority order
1. TJRJ
2. STJ
3. STF

## TJRJ
- Prefer the official judgment PDF or official jurisprudence page.
- Typical official domains include:
  - `www3.tjrj.jus.br/gedcacheweb`
  - `www3.tjrj.jus.br/sophia_web`
  - `www.tjrj.jus.br` or equivalent institutional pages
- Use TJRJ first when the controversy is strongly factual or highly local in treatment.

## STJ
- Prefer the judgment itself in official STJ systems, especially SCON or precedentes qualificados pages.
- Use official news pages only as secondary support when they accurately summarize an identified judgment or Tema.
- Favor:
  - Temas repetitivos
  - Sumulas
  - Judgments that reaffirm the same ratio more recently

## STF
- Prefer Tema, tese, repercussao geral, sumula vinculante, or directly aderent collegiate judgment.
- Use STF only when there is real constitutional fit; do not cite STF mechanically in ordinary consumer disputes.

## Recency rule
- Between equivalent official authorities, prefer the more recent one.
- If using an older leading case, explain it only through a shorter reference or pair it with a newer reaffirmation.

## Do not use by default
- Jusbrasil
- Blogs
- Secondary summaries that are not official court pages
- Unofficial mirrors when the official source is available
